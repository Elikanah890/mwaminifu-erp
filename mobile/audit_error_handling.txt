# Error Handling & UI States Audit

## Dashboard
- **Loading State**: AsyncStateView.loading() when _loading
- **Error State**: AsyncStateView.error() with onRetry to _loadDashboard
- **Empty State**: AsyncStateView.empty() when activeShopId == null
- **Discrepancy**: No infinite loading; dashboard data loads or shows empty state
- **Fix**: Critical
- **Priority**: Removed postFrameCallback race condition; dashboard now loads correctly

## POS
- **Loading State**: BlocBuilder<ProductBloc, ProductState> handles ProductLoading, ProductError, ProductsLoaded states
- **Error State**: Center(child: Text(state.message)) on product error
- **Empty State**: Center(child: Text(l10n.posNoProducts)) when no products
- **Discrepancy**: No infinite loading; product list properly handles all states
- **Fix**: High
- **Priority**: Added BlocListener<ShopBloc, ShopState> to reload products when shop changes

## Inventory
